# 프롬프트 최적화

**결과물은 프롬프트 자체다.** 사용자가 요청한 작업을 수행하는 게 아니라, 다른 AI에 보낼
프롬프트를 만들어 건네는 것이 목적이다. 헷갈리지 말 것 — 작업까지 해버리면 요청을 어긴 것이다.

지침 원본: `D:\제작 프로그램\AI-prompt-interviewer\prompts\targets.md`
(다른 기기라면 이 저장소의 `prompts/targets.md`)

## 1. 대상 AI 확인

사용자가 대상을 말했으면 그대로 쓴다. 말하지 않았으면 **가장 적합한 대상을 추천**하고,
그것을 첫 질문의 선택지로 넣는다. 근거를 한 줄로 밝힌다 — 조사가 필요하면 Perplexity,
긴 문서·코드 추론이면 Claude, 이미지면 이미지 생성 등.

## 2. 인터뷰

`AskUserQuestion`으로 **결과물을 실제로 바꿀 미결정 사항만** 묻는다.
관례적 기본값이 있는 것, 코드를 읽으면 알 수 있는 것은 묻지 않는다.

제약을 지켜야 한다:

- 한 번 호출에 **질문 4개까지**, 질문마다 **선택지 2~4개까지**, `header`는 **12자 이내**
- 자유 입력 칸은 자동으로 붙으므로 "기타" 선택지를 만들지 않는다
- 가장 그럴듯한 선택지를 첫 번째에 두고 라벨에 `(추천)`을 붙인다
- 각 선택지의 `description`에는 **그 선택이 결과를 어떻게 바꾸는지** 한 줄로 쓴다

한 번에 다 묻는다. 4개를 넘겨야 할 만큼 불확실하면 애초에 질문을 잘못 고른 것이다.

## 3. 지침 읽기

`prompts/targets.md`에서 **`## 공통`과 `## <대상>`** 두 섹션을 읽는다.
대상 섹션이 없으면 공통만 적용하고, 그 사실을 결과와 함께 한 줄로 알린다.

`(추정)` 표시가 붙은 항목은 검증되지 않은 짐작이다. 적용해도 되지만 그것에 기대어
프롬프트 구조를 크게 틀지는 않는다.

## 4. 프롬프트 작성

- 원본 요청과 인터뷰 답변을 재료로, 대상 지침에 맞는 구조로 다시 쓴다.
- **원본에 없던 요구사항을 만들어내지 않는다.** 표현과 구조만 바꾸고 의미는 보존한다.
- 이 프로젝트에서 작업 중이면 실제 파일을 읽어 프레임워크·버전·규약을 프롬프트에 박아 넣는다.
  브라우저 확장이 절대 못 하는 일이고, Claude Code로 온 이유의 핵심이다.
- 완성된 프롬프트는 **코드 블록 하나**로 보여준다. 사용자가 그대로 복사할 수 있어야 한다.

## 5. 전달

프롬프트를 보여준 뒤, 대상이 확장이 지원하는 사이트(ChatGPT, Gemini, Grok, Claude,
Perplexity, Copilot)면 브라우저로 바로 보낼 수 있다고 알리고 원하는지 묻는다.

```
node scripts/send-to-browser.mjs <chatgpt|gemini|grok|claude|perplexity|copilot> "<프롬프트>"
```

프롬프트가 길면 인자 대신 stdin으로 넘긴다. 이 명령은 브라우저를 열어 입력창에 프롬프트를
넣어주지만 **전송은 하지 않는다** — 마지막 확인은 사용자가 한다.

저장소 밖에서 작업 중이라 스크립트를 못 찾으면 코드 블록만 보여주고 끝낸다. 억지로 찾지 않는다.
