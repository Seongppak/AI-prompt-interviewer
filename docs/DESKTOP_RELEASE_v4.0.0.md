# AI Prompt Interviewer Desktop v4.0.0

AI 앱에서 작성한 초안을 가로채 짧은 인터뷰를 진행하고, 확정된 답변을 바탕으로 더 구체적인 최종 프롬프트를 만든 뒤 원래 입력창으로 돌려보내는 Windows x64 데스크톱 정식판입니다.

## 주요 기능

- ChatGPT, Claude, Codex 및 IDE AI 채팅 입력창의 Enter·전송 버튼 가로채기
- 일반 검색창과 편집기는 제외하는 대상 앱·입력창 판별
- 한글을 포함한 UTF-8 프롬프트 캡처 및 원래 채팅창 자동 입력
- 인터뷰 답변을 반영한 역할·목표·제약·절차·출력 형식·품질 기준 생성
- 부족한 초안을 자동 감지해 Gemini로 한 차례 추가 품질 보정
- Gemini API 키 암호화 저장 및 발급 페이지 바로가기
- 프로젝트와 인터뷰 기록의 영구 저장
- 전역 클립보드 캡처 단축키와 Desktop Target Adapter

## 설치

1. `AI Prompt Interviewer-Setup-4.0.0-x64.exe`를 내려받아 실행합니다.
2. 설치 경로를 선택하고 설치를 완료합니다.
3. 앱에서 Gemini API 키를 입력한 뒤 **저장**을 누릅니다.
4. 대상 앱 가로채기를 켜고 지원되는 AI 채팅 입력창에서 사용합니다.

## 호환성 및 참고

- 운영체제: Windows 10/11 64비트
- 아키텍처: x64
- 기존 브라우저 확장 프로그램은 변경하지 않았으며 데스크톱판과 별도로 사용할 수 있습니다.
- 현재 실행 파일은 코드 서명 인증서로 서명되지 않았습니다. Windows SmartScreen 경고가 표시되면 게시자와 릴리스 출처를 확인한 뒤 실행하세요.
- 설치 파일과 함께 제공되는 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.
