# AI Prompt Interviewer Web v4.0.1

Chrome 웹 확장 프로그램 릴리스입니다.

## 변경 사항

- 사이드패널의 X 버튼은 패널만 닫습니다. 가로채기 기능은 상단 전원 버튼으로 따로 제어합니다.
- Enter를 500ms 안에 두 번 누르면 현재 질문만 인터뷰 없이 바로 전송합니다. 다음 질문에서는 가로채기가 다시 작동합니다.
- Ctrl+Enter(Mac: Command+Enter) 또는 설정에서 선택한 Alt+Enter로 현재 질문만 바로 전송할 수 있습니다.
- 보내기 버튼과 Enter 처리 순서를 개선하고 다음 질문의 가로채기 복귀를 검증하는 회귀 테스트를 추가했습니다.

## 설치 및 업데이트

1. Release의 `AI-Prompt-Interviewer-Web-4.0.1.zip`을 다운로드하고 별도 폴더에 압축을 풉니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
3. 신규 설치는 압축해제된 확장 프로그램 로드에서 `manifest.json`이 있는 폴더를 선택합니다.
4. 기존 설치는 기존 확장의 폴더에 새 파일을 반영한 뒤 확장의 새로고침 버튼을 누릅니다.
5. 사용 중인 AI 사이트도 새로고침합니다. 기존에 가로채기를 껐다면 패널의 전원 버튼을 다시 켭니다.

현재 질문의 일회성 우회는 저장된 전원 설정을 바꾸지 않습니다.
다운로드의 SHA-256은 함께 제공하는 `.sha256` 파일로 확인할 수 있습니다.

## 배포 범위

이 릴리스는 GitHub에서 ZIP 파일로 배포하는 브라우저 확장입니다.
Chrome 웹 스토어 게시와 Windows 데스크톱 설치 파일 업데이트는 포함하지 않습니다.
