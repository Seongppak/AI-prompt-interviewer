# AI Prompt Interviewer Desktop v4.0.2

공용 Core의 추천값 검증 오류를 수정한 Windows x64 데스크톱 릴리스입니다.

## 수정 내용

- AI가 `isolation_method` 등 질문의 추천값으로 선택지 표시 이름을 반환하면, 정확히 하나의 선택지와 일치할 때 실제 선택지 값으로 변환합니다.
- 존재하지 않거나 모호한 추천값은 추천 표시와 추천 이유만 제거합니다. 유효한 질문과 선택지는 유지하여 인터뷰를 계속 진행합니다.
- AI 생성 지시에 추천값은 해당 질문의 선택지 값을 그대로 사용해야 한다는 조건을 추가했습니다.
- 비어 있거나 중복된 선택지 등 필수 구조 검증은 유지합니다.

## 설치

1. `AI-Prompt-Interviewer-Setup-4.0.2-x64.exe`를 다운로드합니다.
2. 실행 중인 AI Prompt Interviewer를 종료하고 설치 파일을 실행합니다.
3. 설치 후 문제가 발생했던 질문으로 새 인터뷰를 시작합니다. 저장된 과거 오류는 자동으로 재실행되지 않습니다.

Windows 10/11 x64를 대상으로 합니다. 이 릴리스는 커밋된 소스만 사용하며, 작업 폴더에 남아 있는 다른 데스크톱 변경은 포함하지 않습니다.
설치 파일과 함께 제공되는 SHA-256 체크섬으로 다운로드 무결성을 확인할 수 있습니다.
Chrome 확장 프로그램은 별도 Web 릴리스이며, 이번 오류 수정은 Core를 사용하는 앱에 적용됩니다.
